# 디자인 데모 테스트 기록

검토일: 2026-11-13 · 브라우저에서 수행한 UI 테스트입니다.

## 확인한 동작

- 수업 이름, 2모둠, 모둠당 8명, 10분 설정으로 방 생성
- 입장 학생이 없을 때 수업 시작을 방지하는 안내
- 예시 학생 16명 입장 후 시작
- 일시정지와 정확한 2분 추가(09:59 → 11:59)
- 선생님 안내를 학생 미리보기에서 확인
- 학생·선생님 전환 후 같은 수업의 시간·안내 유지
- 추리 단계와 회고 완료, 16명·2모둠·10분 표시
- 모둠별 역할표에서 타인의 희망 순위와 진행 중 비밀 정체를 숨김
- 역할의 목표·걱정으로 발언 준비, 찬반 선택 버튼 없음
- 1순위 클릭, 2순위 드래그 선택과 미배정자의 역할 전환자 처리
- 혼자 연습을 선생님으로 시작하고 학생 시점으로 전환한 뒤 같은 PRACT1 수업 복귀

## 수정한 문제

- 설정 다시 보기에서 선택한 주제가 초기값으로 돌아가던 문제
- 연습 후 새 일반 방을 만들 때 연습 코드가 유지되던 문제

두 문제는 수정 후 스마트폰 주제로 새 방 생성 → 설정 다시 보기에서 주제 유지, 일반 코드 `WS2046` 표시로 재확인했습니다.

## VS Code 패키지 자체 검증

- 패키지 폴더에서 `npm run check`, `npm test` 통과
- 패키지의 `npm start`로 별도 포트 4174에서 실제 실행
- 혼자 연습하기 → 선생님으로 시작 → 수업 시작 → 일시정지 확인
- iPad 834×1112: 가로 넘침 없음, 연습 시점 전환 바 표시
- Galaxy Tab 800×1280: 가로 넘침 없음, 하단 터치 수업 제어 바 표시
- 노트북 1440×1000: 가로 넘침 없음, 데스크톱 레이아웃 표시

## 전체 페이지 공통 레이아웃 수정

- 연습 시점 전환 바를 본문 위의 가로 도구 모음으로 배치
- 연습 바가 본문과 가로로 나뉘어 화면을 절반씩 차지하던 문제 수정
- 작은 화면의 선생님 수업 진행 카드가 가로로 넘치던 문제 수정
- 학생·선생님 14개 페이지를 1920×1080, 1440×1000, 834×1112, 800×1280, 약 390×844에서 검사: 총 70개 조합 모두 연습 바가 본문 위에 표시되고 페이지 가로 넘침 없음
- 일반 모드 14개 페이지의 공통 세로 배치 확인

## 검사 환경과 구현 범위

노트북과 태블릿 레이아웃은 브라우저 화면 크기를 바꿔 검사합니다. 실제 iPad/Galaxy Tab 하드웨어에서 테스트한 결과는 아닙니다. 다른 기기의 다중 접속, 실제 음성인식·AI·서버 저장·인증은 이 데모의 구현 범위가 아닙니다. 상세 역할은 AI 과제 주제의 예시이고, 역할 배정 정책은 README의 데모 가정을 따릅니다.
