# whose side? — 학생 UI·UX 데모

**제품명: whose side? · 제작 팀: Bridge**

학생이 비밀 역할을 맡아 **목소리로 토론하고, 말하는 동안 AI가 내용을 요약하는 경험**을 보여주는 회의용 디자인 데모입니다. 기존 서비스와 분리된 정적 웹사이트입니다.

흰색·연한 회색 바탕, 절제된 파란색 버튼, 읽기 쉬운 글자와 일관된 여백으로 구성했습니다. 데스크톱과 모바일 화면을 지원합니다.

인터넷이 연결된 컴퓨터나 모바일 브라우저에서 로그인이나 설치 없이 접속할 수 있습니다.

## 다른 컴퓨터에서 열기

1. 이 저장소의 **Code → Download ZIP**을 누르고 압축을 풉니다. 또는 Git으로 이 저장소를 복제합니다.
2. 폴더 안의 **`dist/index.html`**을 Chrome 또는 Edge로 엽니다. 설치나 API 키가 필요 없습니다.
3. 코드를 수정하려면 내려받은 폴더 전체를 코드 편집기에서 엽니다.

로컬 서버가 필요하면 Node.js가 설치된 환경에서 다음을 실행합니다. 별도 패키지 설치는 필요 없습니다.

```sh
npm start
```

터미널에 표시되는 `http://127.0.0.1:4173/#entrance`로 접속합니다. 종료는 `Ctrl+C`입니다. 자바스크립트 문법 확인은 `npm run check`로 실행합니다.

## 시연 흐름

**시작 → 주제 소개 영상 → 게임 소개 영상 → 게임 규칙 → 대기실 → 내 역할 → 생각 정리 → 음성 토론·실시간 요약 → 추리 → 결과 → 회고**

- 방 코드는 **`BR2046`**입니다. **먼저 연습해보기**로도 입장할 수 있습니다.
- 주제 소개 영상과 게임 소개 영상은 **동일한 양식**을 사용합니다. 실제 영상 없이 다음 단계로 진행할 수 있습니다.
- 안내 중 새로고침하면 현재 단계를 유지합니다. 규칙 확인 후 대기실로 입장합니다.
- **말하기 시작** 또는 `Z`로 발언 시연을 시작하고, **말하기 마치기** 또는 `X`로 마칩니다.
- 발언 중 요약, 발언 원문, 요약 기록, 개인 메모를 확인할 수 있습니다.
- 상단 화면 메뉴와 **모바일** 버튼으로 회의 중 화면을 살펴볼 수 있습니다.
- 기본 주소는 핵심 기능인 토론 화면을 엽니다. 첫 화면부터 시연하려면 주소 끝에 `#entrance`를 붙이거나 상단 **시작**을 누릅니다.

## 데모 범위

이 저장소에 업로드한 최신 소스는 기존 온라인 데모에 자동 배포되지 않습니다. 최신 변경 사항은 이 소스를 내려받아 확인합니다.

[학생·선생님 통합 흐름]
- 첫 화면에 학생 코드 입장, 선생님 방 만들기, 혼자 연습하기가 있어야 합니다.
- 선생님의 주요 시작 행동은 "방 만들기"입니다.
- 학생 화면 경로:
  #entrance → #orientation → #lobby → #role → #briefing →
  #discussion → #vote → #result → #reflection
- 선생님 화면 경로:
  #teacher → #teacher-create → #teacher-lobby → #teacher-live → #teacher-report
- 학생은 규칙 확인 후 대기실에 들어가도록 하고 새로고침·시점 전환 시 진행 상태를 보존하세요.
- 선생님은 주제·모둠 수·모둠당 인원·시간을 설정하고 방을 만듭니다.
  예시 학생 입장, 수업 시작, 일시정지/다시 시작, 정확히 2분 추가, 안내 공유,
  모둠 관찰, 추리 단계 이동, 수업 마무리와 회고가 동작해야 합니다.
- 설정 다시 보기에서 선택한 주제를 유지하고, 연습 후 일반 방 생성 시 연습 상태를 해제하세요.
- 학생/선생님은 같은 브라우저의 같은 수업 상태를 공유해야 합니다.
  시점 전환으로 시간·공지·방 설정·학생 진행 단계를 초기화하지 마세요.

[혼자 연습하기]
- 시작할 때 "학생으로 연습하기"와 "선생님으로 연습하기"를 선택할 수 있어야 합니다.

- 시점 전환 시 새 방이나 별도 데모를 만들지 말고 동일한 수업을 계속 사용하세요.
- 연습 코드는 PRACT1, 선생님 일반 방 생성 시 시연 코드는 WS2046,

[역할 선택·배정·비밀 정체]
- 실제 생각과 가까운 역할의 1순위·2순위를 고르는 롤 매칭 방식입니다.
- 순위 버튼 클릭과 카드 드래그를 모두 지원하고, 터치 드래그도 처리하세요.
  선택된 역할·순위 표시, 변경·해제·중복 방지·완료 버튼 상태는 기준 구현을 따르세요.
- 1순위 우선 배정 → 남은 자리에 2순위 배정 → 둘 다 미배정인 사람은 역할 전환자입니다.
  역할 전환자는 자신이 고르지 않은 역할을 맡습니다. 동순위 충돌은 입장 순서로 처리합니다.
- 현재 데모는 역할별 한 자리 가정이고 사용자는 마지막 입장입니다.
  원본 서비스의 중복 배정 정책과 동일하다고 주장하거나 임의로 다른 엔진을 만들지 마세요.
- 역할에 따라 목표·걱정·관점과 찬반 입장이 생기는 구조입니다.
